# @metis/custom-theme

DeepSeek Harness theme customization plugin with a built-in default preset (`aurora-blue`), curated presets, interactive light/dark `--dsw-*` token editor, arbitrary custom CSS variables, sidebar logo/title customization, JSON import/export, Host persistence (`$DSH_HOME/custom-theme.json`), and zero-flash `<head>` CSS injection via `webserver/index-inject`.

## Build & Test

```bash
node scripts/build.mjs
node .test/run.mjs
```
