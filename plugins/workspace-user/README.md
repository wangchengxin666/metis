# @metis/workspace-user

DeepSeek Harness plugin that renders the signed-in workspace user at the bottom-left of the sidebar (`settings.launcher`), highlights administrator access (including when an admin inspects another user's workspace), and provides a popup quick-action menu (`Settings`, `Back to My Workspaces (/my)`, `Admin Console (/admin)`, and `Sign Out (/auth/logout)`).

## Build & Test

```bash
node scripts/build.mjs
node .test/run.mjs
```
